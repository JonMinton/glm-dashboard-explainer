# GLM Dashboard Explainer

Interactive, step-by-step pages for learning generalised linear models, optimisation, inference and resampling methods. Standalone HTML and vanilla JavaScript, served from `docs/`; live at [stats-board.jonminton.net](https://stats-board.jonminton.net). Companion course site: [stats.jonminton.net](https://stats.jonminton.net) ([repo](https://github.com/JonMinton/JonStats)).
